# Analysis programme

## Canonical ecological mainline

The current Azores paper is **not** a site-fidelity re-analysis and not an EOG validation paper.

Primary result:

> **Capture-time silvering readiness strongly predicts migration activation and earlier onset, but the same Durif gradient is absent from post-activation migration speed.**

- upstream repository: `PieterjanVerhelst/eel-meta-analysis`

## 1. Binary migration activation

~~~bash
python analysis/09_durif_migration_initiation.py
~~~

Expert-corrected result:
- FIII: **154/261 = 59.0%**
- FIV: **53/68 = 77.9%**
- FV: **215/246 = 87.4%**

## 2. Time to behavioral onset

~~~bash
python analysis/10_migration_onset_cox.py
~~~

- HR/stage: **1.29**
- 95% CI: **1.13–1.47**
- p = **0.00016**

This uses the source threshold-defined downstream-migration crossing rather than treating a release-row migration flag as natural physiological onset.

## 3. Post-activation migration speed

~~~bash
python analysis/12_post_initiation_speed.py
~~~

Among expert-corrected initiated eels:
- speed ratio/stage: **0.983**
- 95% CI: **0.852–1.134**
- p = **0.815**

This is the primary progression result because it does not require recoding unobserved terminal outcomes as biological failures.

## 4. Terminal-endpoint membership — sensitivity only

The upstream positive terminal set is generated by project-specific sea/terminal station rules.

The source meta-analysis explicitly did not estimate escapement success rate.

Therefore:
- non-membership is not treated as validated failure;
- conditional terminal-endpoint OR and the stacked initiation/completion interaction are retained only as secondary sensitivity analyses;
- do not use them as the primary phase-control claim.

See:
- `docs/escapement_endpoint_audit.md`
- `results/phase_control_canonical_v2.json`

Historical scripts remain reproducible for audit, but their binary completion interpretation is not manuscript-primary.

## 5. External context

The source meta-analysis independently reports variation in migration speed with tidal context and water-regulating structures, with strong water-body-specific hydrological dependence.

The active independent confirmation target is the Dutch pump -> tidal-sluice route.

python analysis/08_dutch_barrier_confirmation_gate.py --data-dir <downloaded_DANS_directory>

## Interpretation boundary

The paper may claim:

> **internal migratory readiness strongly predicts activation, while no general stage gradient is detected in post-activation migration speed.**

It may not claim:
- Durif stage causes migration;
- terminal non-membership is migration failure;
- escapement probability is estimated here;
- external conditions causally replace internal state after activation;
- Durif has exactly zero post-activation influence.
