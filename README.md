# azores

Independent ecological project on yellow-eel space use and movement in an island-stream landscape.

## Scientific origin

This project grew from an EOG fresh-data result: a time-updated spatial/history state improved held-out receiver-week detection beyond an already rich conventional predictor, but EOG could not identify the biological mechanism.

The project therefore asks **what ecological process creates that residual history dependence** rather than whether EOG improves prediction.

Current hypothesis family:

1. local residence / site-use memory;
2. hydrological disturbance resets that memory;
3. island-stream geometry compresses realised yellow-eel movement.

See [docs/idea_origin_from_eog.md](docs/idea_origin_from_eog.md).

## Boundary

EOG is provenance only. Ecological claims here require direct analysis of eel observations or independent comparative data.
