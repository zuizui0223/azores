# azores

Independent ecological project on yellow-eel space use and movement in an island-stream landscape.

## Scientific origin

This project grew from an EOG fresh-data result: a time-updated spatial/history state improved held-out receiver-week detection beyond an already rich conventional predictor, but EOG could not identify the biological mechanism.

The critical ecological clue is that the source study observed **no receiver-to-receiver movement among the 36 tagged eels**. The EOG gain therefore should not be read as evidence of dispersal. The leading interpretation is persistent local pool-state memory, with activity/detection dynamics and hydrological synchrony as competing explanations.

## Current question

> **In a strongly resident yellow-eel population, is temporal predictability generated primarily by persistent local residence, time-varying detectability/activity, or hydrologically synchronized pool dynamics?**

Next model ladder:

1. seasonal/effort baseline;
2. same-tag / same-pool memory;
3. neighbouring-pool state;
4. hydrology and memory × hydrology;
5. latent residence + acoustic detection model.

## Evidence boundary

The Azores response has already been opened in EOG. Analyses using the same telemetry are exploratory mechanism diagnosis. Independent confirmation requires another stream, population, time series, or external telemetry dataset.

EOG is provenance only. Ecological claims here require direct ecological evidence.
