# Project-context gate: resistance aligns with completion, not initiation

## Question

The Europe-wide panel now supports a two-stage movement decomposition:

1. internal readiness strongly predicts whether migration begins;
2. after migration begins, the general Durif-stage advantage becomes weak.

A new diagnostic asks:

> **Does the source study's landscape-resistance context align differently with these two gates?**

This is a six-project developmental analysis. It is not a causal WRS test.

## Project context

For the six projects with compatible migration tables, the median individual WRS impact score is:

| project | median WRS impact |
|---|---:|
| 2015 Scheldt / phd_verhelst_eel | 0 |
| Grote Nete | 0 |
| Warnow | 1 |
| ESGL | 3 |
| Leopold Canal | 5 |
| Albert Canal | 14 |

Within most projects, WRS is nearly or completely constant. Therefore WRS remains strongly confounded with project/system identity.

## Gate 1 — migration initiation

After applying the source-study expert nonmigrant exclusions, project-level initiation rates do **not** order with median WRS.

Across six projects:

- Spearman rho = **+0.029**
- exact two-sided permutation p = **0.983**
- permutation space = all **6! = 720** project assignments.

The same conclusion holds after standardizing each project's initiation rate to the common FIII/FIV/FV composition of the six-project tracked cohort.

Interpretation:

> **the coarse project-level resistance score does not explain which projects have more migration initiation.**

That is consistent with the independent result that capture-time Durif readiness is the stronger Gate-1 predictor.

## Gate 2 — completion after initiation

Completion means appearance in the published successful-migrant endpoint, conditional on classified migration having begun.

Project-level completion fractions:

| project | successful / initiators | completion |
|---|---:|---:|
| Grote Nete | 33 / 33 | **1.000** |
| 2015 Scheldt | 76 / 86 | **0.884** |
| ESGL | 10 / 12 | **0.833** |
| Warnow | 87 / 107 | **0.813** |
| Leopold Canal | 36 / 52 | **0.692** |
| Albert Canal | 25 / 132 | **0.189** |

Against median project WRS:

- Spearman rho = **-0.928**
- exact two-sided permutation p = **0.0222**

Leave-one-project-out rho remains negative:

- range approximately **-0.97 to -0.87**.

Using a common reference FIII/FIV/FV composition for every project does not change the qualitative rank result.

Thus:

> **higher project-level WRS is associated with lower conversion from initiated migration to the successful endpoint, while showing essentially no association with migration initiation itself.**

## Why this matters biologically

The same external descriptor behaves differently across sequential movement stages.

The observed pattern is compatible with:

~~~text
internal readiness
      |
      v
migration initiation
      |
      v
route / barrier / hydrological filter
      |
      v
successful completion
~~~

This is substantially more specific than saying "barriers matter" or "silver stage matters."

It suggests that **motivation/readiness and route completion are distinct ecological bottlenecks**.

## Why this is not causal evidence

The six projects are not six randomized WRS treatments.

Major unresolved confounding includes:

- tracking geometry;
- water-body identity;
- receiver coverage;
- barrier type;
- hydrology;
- latitude/season;
- endpoint observability;
- study-specific handling and release context.

WRS is mostly a project-level variable.

Therefore the negative completion gradient is **hypothesis-generating context evidence**, not proof that the numeric WRS score causes migration failure.

## Revised external confirmation target

The Dutch pump -> tidal-sluice system is now used specifically to test Gate 2.

The key question becomes:

> **among eels that are already migration-ready and have initiated downstream movement, do independently measured passage opportunities and barrier identity explain delay/failure better than Durif readiness itself?**

A stronger confirmation would show:

1. Durif/readiness predicts initiation or pre-barrier movement state;
2. barrier-specific opportunity/discharge predicts passage completion/delay;
3. the post-initiation Durif effect is small or context dependent after opportunity is represented.

## Falsification

The two-gate interpretation weakens if an independent within-route study shows that:

- advanced Durif stage remains the dominant predictor of barrier passage/completion after initiation; and
- barrier/hydrological opportunity contributes little.

## Evidence class

Developmental, post-hoc context diagnostic.

Do not headline the exact p-value as if six projects were experimental replicates.
