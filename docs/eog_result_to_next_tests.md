# From the EOG result to the next ecological tests

## Current position

EOG is no longer the object of inference in this repository. It supplied one anomaly:

> a time-updated spatial/history representation improved future receiver-week detection beyond a baseline that already contained season, receiver position, release geometry, focal-receiver lag history, neighbouring recent detections and cumulative detection history.

The EOG result therefore created a **residual ecological question**, not a mechanism claim.

## What is already known and must not be repackaged

The source study (Verhelst et al. 2026, DOI 10.1111/jfb.70355) already reports restricted movement and strong pool fidelity of yellow-stage European eels in the Azorean stream.

The published cleaned residency table confirms that boundary for the retained EOG cohort:

- 7,664 cleaned residency rows after the same focal filtering;
- 26 retained yellow eels were detected at study receivers;
- 5 study receivers held those detected eels;
- **0/26 detected yellow eels used more than one retained study receiver**.

Therefore the new paper cannot be "yellow eels are resident" or "island streams compress movement." Those are background/motivation unless a genuinely independent comparative dataset is added later.

## First post-EOG ecological screen

The first independent screen uses the upstream published
`data/interim/residency_false_removed.csv` at immutable git blob
`2de3f5e5c9d5decdcc5b632fff9473e644709bc4`.

### Individual weekly persistence

Within each eel's first-to-last detected-week interval:

- detected -> detected: 729 transitions;
- detected -> non-detected: 64;
- non-detected -> detected: 64;
- non-detected -> non-detected: 162.

Thus, descriptively,

- P(next week detected | current week detected) = **0.9193**;
- P(next week detected | current week not detected) = **0.2832**;
- pooled risk difference = **0.6361**.

This is a persistence signal in **observed detection**, not an occupancy estimate.

### Locality of weekly detection association

For eel pairs with at least 12 overlapping tracking weeks:

- same-receiver pairwise weekly-detection correlation: mean **0.1421** (n = 39);
- different-receiver correlation: mean **-0.0094** (n = 96);
- same-minus-different difference: **0.1527**.

A receiver-label permutation screen (10,000 permutations; fixed seed 20260930)
gave a one-sided p = **0.00730**.

This is exploratory. It does not identify why eels sharing a receiver covary.

## Revised biological question

The EOG anomaly plus the post-EOG screen now points to a narrower question:

> **Why do co-resident yellow eels show temporally persistent, locally clustered detection states even though they do not move among retained pools?**

This is different from the original movement-range question.

## Competing explanations

### H1 — pool-level biological state

Eels sharing a pool respond to a common local ecological state: water depth,
flow, refuge availability, prey activity, temperature, oxygen or another
pool-level condition.

Prediction:

- after accounting for individual detection history, a shared pool-week random
  state still explains covariation among co-resident eels;
- that shared state is weak or absent between pools;
- externally measured environmental variation should predict the inferred
  pool-week state.

### H2 — receiver/tag observation state

The apparent pool-level synchrony is generated by acoustic observation:
receiver performance, deployment state, attenuation, tag characteristics or
other local detection conditions.

Prediction:

- receiver-week effects explain the covariance without requiring common
  biological activity;
- synchrony aligns with receiver availability/performance and detection effort;
- after observation effects are represented, residual same-pool covariance
  approaches the between-pool baseline.

### H3 — shared biological activity rhythm

Eels remain resident but switch between detectable and less-detectable activity
states together within a pool (for example diel shelter emergence).

Prediction:

- co-resident eels show excess synchrony at sub-weekly/diel scales, not merely
  week-level presence;
- phase/timing of detections is more similar within pools than between pools;
- the pattern remains after known receiver-operation intervals are accounted for.

### H4 — hydrological reset

A local or catchment-scale disturbance changes the otherwise persistent activity
state.

Prediction:

- persistence and within-pool synchrony change around independently frozen
  high-flow/rainfall/drying events;
- disturbance effects should be estimated only after H1-H3 observation
  separation, not inferred from the EOG result itself.

## Next validation sequence

### T1 — reproduce the screen

Run:

```bash
python analysis/run_residency_screen.py
```

The output is `results/azores_residency_screen.json`.

### T2 — observation-versus-pool-state decomposition

Build an eel x week detection table and compare:

1. individual-history-only model;
2. individual + receiver observation-state model;
3. individual + shared pool-week latent-state model;
4. both observation and pool-state terms.

Primary target:

> Does a shared pool-week component remain after receiver/tag observation
> heterogeneity is represented?

This is the first genuinely new ecological test.

### T3 — sub-weekly activity synchrony

If T2 leaves a biological pool-state signal, return to detection timestamps and
test whether co-resident eels share diel/activity transitions more strongly than
eels in different pools.

### T4 — external driver test

Only after T2/T3 establish a residual biological state should hydrology,
temperature, rainfall or drying events be added from an independently frozen
external source.

### T5 — comparative movement compression (future extension)

A cross-system claim about habitat geometry compressing realised movement needs
independent yellow-eel telemetry from larger rivers/lakes/estuaries. The Azores
dataset alone cannot establish that relationship.

## Claim rules

- Receiver-week non-detection is not biological absence.
- Weekly detection persistence is not movement persistence.
- Same-receiver covariance is not automatically a pool-level ecological effect.
- The EOG predictive increment is only the origin of the question.
- Restricted movement/pool fidelity is published background, not the new result.
- The new contribution must distinguish **shared biological pool state** from
  **shared observation state**, then identify drivers of the biological state if
  it survives.
