# Post-activation Durif heterogeneity result

## Question

The pooled post-activation speed model gives a weak Durif-stage gradient:

- n = 418;
- speed ratio per stage = 0.983;
- 95% CI 0.852–1.134.

A biologically important alternative is that this pooled value hides strong but opposite project-specific effects.

That alternative was tested directly after the canonical speed result was independently reproduced from the pinned upstream blobs.

## Project-specific stage effects

Using the same speed definition and the same within-project release-year, body-length and release-timing structure:

| Project | n | speed ratio / Durif stage | 95% CI |
|---|---:|---:|---:|
| 2011 Warnow | 107 | 0.915 | 0.682–1.228 |
| 2012 Leopoldkanaal | 52 | 0.981 | 0.678–1.420 |
| 2013 Albertkanaal | 128 | 1.272 | 0.899–1.799 |
| 2015 phd_verhelst_eel | 86 | 1.011 | 0.856–1.193 |
| 2019 Grotenete | 33 | 1.035 | 0.731–1.465 |
| ESGL | 12 | 1.219 | 0.675–2.201 |

A model allowing a separate Durif slope in every project did not improve fit over one common Durif slope:

- stage × project interaction F = **1.032**;
- df = **5, 397**;
- p = **0.398**.

A weighted heterogeneity diagnostic was likewise small:

- Q = **2.469** on 5 df.

## Interpretation

The six-project dataset does **not** support the idea that the pooled near-zero Durif effect is simply an average of strong positive effects in some systems and strong negative effects in others.

Thus the current supported pattern remains:

> **Durif readiness is strongly transferable as an activation predictor, whereas the same variable has little general predictive value for post-activation migration speed in this six-project dataset.**

## Important boundary

This result does not show that environment can never modify a stage effect.

Some project-stage cells are sparse, progression definitions differ among studies, and an external system may legitimately show a positive silvering-stage effect.

The present result only says:

> **strong among-project heterogeneity is not demonstrated inside this six-project analysis.**

## Novelty implication

The paper should not be reframed around a supported stage × route-context interaction.

The more defensible contribution is narrower:

1. one independently measured internal-state axis has a strong and reproducible association with activation and onset;
2. the same axis has weak pooled association with generic post-activation speed;
3. that attenuation is not explained, in this dataset, by obvious project-specific sign cancellation.

This is a phase-specific empirical decomposition, not a new theory that internal and external control always switch at a fixed migration boundary.
