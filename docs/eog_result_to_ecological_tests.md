# From the EOG result to ecological tests

## Status

This document converts the already-observed EOG result into **post-hoc ecological hypotheses** and then into explicit next tests.

The EOG result is not itself a mechanism test. Any test using the same Azores telemetry remains exploratory/mechanism-diagnostic. Independent confirmation requires a new population, stream, period, or other genuinely external data.

## 1. What the EOG result actually says

The frozen Azores endpoint was receiver-week observed detection.

The conventional arm already included season, receiver coordinates, receiver active days, network degree at three frozen scales, release-anchor abundance/distance/exposure, previous-week detection, time since last detection, cumulative previous detections, previous-week detected-receiver count, neighbouring previous-source counts/exposures, and cumulative global detections.

Adding the unchanged EOG world-support summary improved held-out macro log loss from **0.1422727 to 0.1322871** (about **7.0%**), with the augmented arm better in **5/5** held-out blocks.

Therefore the defensible empirical statement is:

> A sequentially updated spatial-history state contained held-out information about future receiver-week detection that was not fully redundant with the already-rich conventional predictor.

It is not evidence that any frozen EOG world was the true movement process.

## 2. Why a movement explanation is not the default

The source study tracked 36 yellow-stage European eels for one year. None was detected at more than one receiver; detections were confined to the receiver nearest the release location, supporting very high site fidelity and a home range below 1 km, probably substantially smaller.

The stream itself is a short island system composed of pools separated by riffles/runs and waterfalls, and parts can seasonally dry.

Source study:
- Verhelst et al. 2026, *Journal of Fish Biology*, DOI: 10.1111/jfb.70355
- https://doi.org/10.1111/jfb.70355

This makes the following interpretation especially important:

> **The EOG gain occurred in a system with no observed receiver-to-receiver movement. Therefore the added information need not be movement information.**

The EOG state may instead be summarising persistence and turnover in which pools are currently producing detections.

## 3. Primary ecological interpretation

### H-A1 — persistent local-state memory

The first ecological explanation to test is that yellow eels create long-lived local residence states.

A pool that is currently occupied/detecting is more likely to remain in that state because the same individual remains locally resident. The EOG sequential state can then improve prediction by summarising the configuration of persistent local states, even if no eel moves between receiver pools.

This is stronger and more precise than saying "site fidelity exists": the published study already establishes restricted movement. The new question is whether **temporal predictability is generated by persistence of local residence states**.

### Prediction

After controlling for season and receiver effort, the strongest temporal coefficient should be same-individual / same-pool persistence, not neighbouring-pool state.

If the spatial-neighbour contribution is removed while same-pool history is retained, most of the predictive signal should remain.

## 4. Competing explanations

### H-A2 — activity/detection memory rather than occupancy memory

An eel can remain in the same pool while acoustic detectability changes with behaviour, microhabitat use, tag conditions, or receiver performance.

Prediction:
- detection gaps followed by reappearance occur at the same receiver without evidence of relocation;
- a latent resident state with time-varying detection explains the data better than models that interpret every non-detection as local absence.

### H-A3 — hydrological disturbance resets local state

Because parts of the island stream can seasonally dry, rainfall/flow may alter pool connectivity, water depth, activity, or local persistence.

Prediction:
- the effect of previous local state on current detection weakens during hydrological disturbance;
- long dry or high-flow intervals increase state switching or long detection gaps;
- a previous-state × hydrology interaction improves explanation beyond season alone.

### H-A4 — shared hydrological state creates apparent network information

Neighbouring pools may respond synchronously to rainfall/flow even if eels do not move among them.

Prediction:
- neighbouring-receiver detections covary after conditioning on same-pool persistence;
- that covariance weakens substantially after adding hydrological covariates.

If supported, the "network" signal is environmental synchrony, not dispersal.

## 5. Next test: mechanism decomposition

### Unit

Primary: individual-tag × week where possible.

Secondary: receiver × week for direct comparability with the EOG endpoint.

### Model ladder

**M0 — seasonal/effort**
- week/season
- receiver active days
- receiver identity or spatial position

**M1 — local memory**
- M0
- previous same-tag/same-pool detection state
- time since last detection
- cumulative local detection history

**M2 — spatial-neighbour state**
- M1
- detections in neighbouring receivers at predeclared distance bands

**M3 — hydrology**
- M2
- rainfall / flow / drying proxy
- local-memory × hydrology interaction

**M4 — latent residence/detection model**
- latent resident state
- observation model for acoustic detection
- persistence and state-transition parameters
- hydrology on state transitions and/or detection

### Primary contrasts

1. **M1 vs M0:** is there local ecological memory?
2. **M2 vs M1:** does neighbouring-pool state add information after local memory?
3. **M3 vs M2:** is the residual spatial/temporal structure explained by hydrology?
4. **M4 vs observed-state models:** can imperfect detection/activity explain apparent state switching?

## 6. Interpretation rules

### If M1 explains nearly all of the gain

Interpretation:
> EOG mainly rediscovered persistent pool residence as a state-memory signal.

This is biologically coherent but not a new movement mechanism.

### If M2 remains important after M1

Interpretation:
> receiver pools have spatially coordinated dynamics beyond individual residence.

Do not call this dispersal until movement between pools is independently observed.

### If M3 removes M2

Interpretation:
> apparent spatial coordination is primarily shared hydrological forcing.

### If M4 strongly improves fit and detection gaps are common

Interpretation:
> part of the EOG history signal arose from observation/activity dynamics within persistent local residence.

## 7. Independence boundary

The Azores raw detection response was already consumed in EOG. Therefore:

- the mechanism decomposition above is **post-hoc exploratory diagnosis**;
- it can generate a biological model and effect-size expectations;
- it cannot serve as independent confirmation of the EOG-generated hypothesis.

Independent confirmation should use another island stream, another time series, or an external yellow-eel telemetry system.

## 8. Scientific question carried forward

> **In a strongly resident yellow-eel population, is temporal predictability generated primarily by persistent local residence, time-varying detectability/activity, or hydrologically synchronized pool dynamics?**

This is now the primary ecological target of the Azores repository.
