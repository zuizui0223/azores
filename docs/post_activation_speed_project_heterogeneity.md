# Post-activation Durif-speed heterogeneity across projects

## Why this test was run

A newly published River Test study (Moyo et al. 2026, Hydrobiologia, DOI 10.1007/s10750-026-06406-6) retained silvering stage in a model of downstream progression rate together with environmental and route variables.

That makes a simple universal statement that silvering state "stops mattering" after migration activation too strong.

A falsifiable alternative is:

> the post-activation effect of migratory readiness is context dependent among water bodies, so a pooled near-zero coefficient hides opposing or strongly different project-specific effects.

## Matched Europe-wide test

Using the same pinned source, speed definition, expert corrections and project-year eligibility rules as the canonical post-initiation speed analysis, the Durif coefficient was estimated separately within each project.

| Project | n | speed ratio / Durif stage | 95% CI |
|---|---:|---:|---:|
| Warnow | 107 | 0.915 | 0.682–1.228 |
| Leopold Canal | 52 | 0.981 | 0.678–1.420 |
| Albert Canal | 128 | 1.272 | 0.899–1.799 |
| Scheldt | 86 | 1.011 | 0.856–1.193 |
| Grote Nete | 33 | 1.035 | 0.731–1.465 |
| ESGL | 12 | 1.219 | 0.675–2.201 |

A fixed-effect heterogeneity audit gives:

- Cochran Q = **2.47**
- df = **5**
- p = **0.781**

Thus the six-project dataset does **not** support the idea that its pooled near-null stage coefficient is caused by strong opposing project-specific effects.

## Updated ecological interpretation

The strongest supported contrast remains:

> **capture-time silvering readiness is a strong and transferable predictor of migration activation and onset, but it is not a strong general predictor of the overall speed of already-active migration in this six-project dataset.**

The River Test result remains useful because it shows that silvering stage can contribute to a different, reach-level progression model in a particular system. But the present six-project audit does not justify upgrading that difference into a demonstrated stage × water-body interaction.

Therefore the manuscript should avoid both extremes:

- not: "internal state becomes irrelevant after activation";
- not: "stage effects reverse among water bodies".

The defensible statement is:

> **the general predictive signal of silvering stage attenuates after activation, while system-specific biological effects may still exist and require endpoint-matched tests.**

## Novelty consequence

This weakens the case for claiming a new universal internal-to-external "control handoff".

The more defensible contribution is methodological-biological but still useful:

> **the same independently measured internal state has sharply different predictive value for distinct phases of one migration sequence.**

Whether route opportunity explains that attenuation is a separate mechanistic question, not yet demonstrated here.
