# Developmental synthesis: stage advantage is context-dependent from onset to success

## Result

Across six public European eel telemetry projects, the within-project effect of advanced Durif stage (FIV/FV) relative to FIII was calculated for two separate outcomes:

1. **detected migration initiation**;
2. **published successful-migrant endpoint**.

A fixed 0.5 Haldane correction was used for every project-level 2x2 table.

The project pattern is strongly coherent across outcomes:

- correlation of project log-ORs: **r ≈ 0.94**
- rank correlation: **≈ 0.94**

Thus, landscapes/projects where advanced-stage eels show a strong advantage in **starting** migration are generally the same landscapes/projects where they show a strong advantage in **successful completion**.

## Context table

| project | dominant barrier context | WRS context | stage advantage |
|---|---|---|---|
| 2015 phd_verhelst_eel | none | 0 / class A | strong |
| 2019 Grotenete | none | 0 / class A | very strong |
| 2011 Warnow | weir/sluice | 1 / class B | moderate |
| ESGL | weir/sluice | 3 / class B | weak |
| 2012 Leopoldkanaal | pumping station/sluice | 5 / class E | strong |
| 2013 Albertkanaal | shipping locks | mostly 14 / class D | absent/reversed |

This pattern immediately rejects an overly simple interpretation:

> **stage advantage is not a monotonic function of a scalar WRS score.**

Leopoldkanaal is especially important: despite a relatively high WRS context, advanced-stage eels show a strong advantage.

## Refined ecological hypothesis

The stronger candidate is not:

> higher landscape resistance always suppresses the effect of migratory readiness.

It is:

> **internal migratory readiness is translated into movement only when the landscape provides a usable passage opportunity; different barrier types may transform the same internal state differently.**

This is an **affordance/opportunity** hypothesis rather than a simple resistance-magnitude hypothesis.

Examples:

- free-flowing route: readiness can be expressed directly;
- pump/sluice: readiness may be expressed during discrete operational/hydrological windows;
- shipping locks: movement may depend on human operation and route geometry in ways that decouple readiness from passage;
- weir/sluice: intermediate outcomes can depend on local opportunity frequency.

## Why this helps the independent test

The Dutch consecutive-barrier system now has a sharper role.

The same tagged eel encounters:

1. a pumping station;
2. a tidal sluice.

This provides a within-route contrast between different passage-opportunity mechanisms without comparing unrelated river systems.

The confirmation target becomes:

> **does Durif readiness interact with barrier-specific passage opportunity, rather than with a generic scalar resistance score?**

## Boundary

There are only six project contexts and barrier type is confounded with project, tracking design and geography.

Therefore the 0.94 coherence is **hypothesis-generating structure**, not causal evidence for barrier type.

Do not fit a six-project regression and present it as a general law.
