# Developmental result: Durif stage predicts migration initiation

## Question

> **Does capture-time morphological migratory readiness predict whether a tracked eel later expresses behavioural migration?**

The public source repository provides migration tracks generated by its frozen migration-classification algorithm.

## Correct initiation definition

The upstream classifier first identifies pointwise downstream-migration starts, then labels the broader migration interval from the first qualifying row to the individual's maximum downstream distance.

Therefore the present analysis uses:

- **initiation-positive** = at least one row with `downstream_migration = TRUE`;
- **threshold-crossing time** = `time_first_dist_to_use` attached to the first qualifying downstream-migration row;
- the arrival time of the first broad `migration = TRUE` row is **not** used as the onset clock.

The inherited thresholds remain unchanged:

- downstream distance threshold: **4 km**;
- migration speed threshold: **0.01 m/s**;
- smoothing threshold: **1005 m**.

For the 2015 `phd_verhelst_eel` project, the nine classifier-positive tags explicitly removed as false migrants by expert judgement in the source processing are treated as non-initiators in the primary result. Algorithm-only values are retained as sensitivity.

The upstream source is pinned to commit:

`59578cb622dddbbba5174b4c51bff0807787385a`

## Cohort

Six projects have compatible exact-stage migration products:

- Warnow;
- Leopold Canal;
- Albert Canal;
- Scheldt / phd_verhelst_eel;
- Grote Nete;
- ESGL.

Joined FIII/FIV/FV individuals: **575**.

Life4fish has stage metadata but no compatible project-level migration file in the source migration directory and is excluded from this endpoint.

## Expert-corrected initiation pattern

| stage | n | initiated | proportion | median days to distance-threshold crossing among initiators |
|---|---:|---:|---:|---:|
| FIII | 261 | 154 | **0.590** | **7.21** |
| FIV | 68 | 53 | **0.779** | **2.14** |
| FV | 246 | 215 | **0.874** | **2.15** |

Algorithm-only sensitivity before the nine source expert corrections:

- FIII: 161/261 = 0.617;
- FIV: 54/68 = 0.794;
- FV: 216/246 = 0.878.

The source correction therefore does not create the stage gradient.

## Adjusted initiation model

~~~text
migration_initiated
  ~ project × release-year fixed effects
  + within-stratum body length
  + within-stratum release timing
  + ordinal Durif stage
~~~

Ordinal coding: FIII=0, FIV=1, FV=2.

Model cohort:

- **525 individuals**
- **11 informative project-year strata**

Per one-stage increment:

- Durif OR = **2.08**
- 95% CI **1.56–2.76**
- p ≈ **4.2e-7**

Body length, +100 mm:

- OR **1.29**
- 95% CI **0.95–1.76**
- p = **0.107**

Release timing, +100 days:

- OR **1.30**
- 95% CI **0.68–2.50**
- p = **0.426**

## Leave-one-project-out stability

Durif OR after each project is removed:

- Warnow: **2.34**
- Leopold Canal: **2.01**
- Albert Canal: **2.35**
- Scheldt / 2015: **1.67**
- Grote Nete: **1.92**
- ESGL: **2.21**

All six leave-one-project-out 95% intervals remain above 1.

## Secondary threshold-crossing latency

Among expert-corrected initiators, a project-year fixed-effects model for log(1 + days to threshold crossing) gave:

- n = **418**
- stage multiplier = **0.715**
- 95% CI **0.585–0.872**
- p = **0.0010**

Advanced-stage eels cross the migration threshold sooner on average, but this timing effect is not fully project-robust: removing the 2015 Scheldt project gives approximately **0.98 [0.80–1.20]**.

Therefore initiation probability is the stronger general result; latency is secondary and system dependent.

## Ecological interpretation

> **Morphological migratory readiness robustly predicts whether later behavioural migration is expressed.**

This places the internal-state signal at the beginning of the movement process rather than only at final escapement.

## Boundary

This does not establish the stronger claim that landscape resistance modifies the effect of internal readiness. That requires phase-specific progression evidence and external route/opportunity tests.

This is developmental independent evidence, not preregistered confirmation.
