# Developmental result: Durif stage predicts migration initiation

## Why this analysis was added

The earlier Europe-wide analysis used the published successful-migrant endpoint.

A stronger biological question is whether capture-time silvering state predicts **the initiation of directed downstream migration itself**, not only final success.

The source repository provides per-project migration files generated by the published migration-classification algorithm.

## Migration-onset definition

The published classifier:

1. searches for downstream movement spanning at least **4 km**;
2. requires migration speed at least **0.01 m/s**;
3. applies a **1005 m** smoothing rule to avoid beginning a migration during an initial stationary phase;
4. marks `migration = TRUE` from the first qualifying downstream-migration row until the individual's maximum downstream distance.

The first `migration = TRUE` row is therefore used as the behavioural-onset marker.

For the 2015 `phd_verhelst_eel` project, the nine individuals explicitly removed as false migrants by expert judgement in the published processing script were also removed from the onset outcome.

## Cohort

Six projects with exact female Durif stages and readable migration tracks:

- 2011 Warnow;
- 2012 Leopoldkanaal;
- 2013 Albertkanaal;
- 2015 phd_verhelst_eel;
- 2019 Grotenete;
- ESGL.

Total FIII/FIV/FV individuals represented in migration files:

**n = 575**

## Raw stage pattern

| Durif stage | tracked n | classified migration onset | fraction |
|---|---:|---:|---:|
| FIII | 261 | 154 | **0.590** |
| FIV | 68 | 53 | **0.779** |
| FV | 246 | 215 | **0.874** |

Descriptive median release-to-onset time among initiators:

- FIII: **4.95 d**
- FIV: **0.27 d**
- FV: **0.69 d**

These onset-time summaries are descriptive only because they condition on having initiated and many advanced-stage animals begin migrating almost immediately after release.

## Adjusted initiation model

To reduce project, year, body-size and seasonal confounding:

~~~text
migration_initiated
  ~ project × release_year fixed effects
  + within-stratum body length
  + within-stratum release timing
  + ordinal Durif stage
~~~

Eleven informative project-year strata contributed **525** individuals.

### Durif stage

Per one-stage increment FIII -> FIV -> FV:

- OR = **2.08**
- 95% CI = **1.56–2.76**
- p = **4.2e-7**

### Body length

Per +100 mm within project-year:

- OR = **1.29**
- 95% CI = **0.95–1.76**
- p = **0.107**

### Release timing

Per +100 d within project-year:

- OR = **1.30**
- 95% CI = **0.68–2.50**
- p = **0.426**

## Ecological interpretation

The internal-state result now appears at two sequential movement endpoints:

1. **migration initiation** — advanced Durif stage strongly increases the probability that directed downstream migration begins during tracking;
2. **successful-migrant endpoint** — advanced Durif stage also predicts later successful movement.

The initiation result is especially useful because it is closer to **movement motivation / release of mobility** than the final successful-migrant endpoint, which additionally depends on landscape passage and monitoring geometry.

This strengthens the first half of the mobility-gating hypothesis:

> **internal migratory readiness regulates whether latent movement capacity is expressed.**

## What remains unresolved

The stronger claim is still not established:

> **landscape resistance changes the effect of internal readiness.**

That requires the external within-landscape barrier test.

## Evidence boundary

This analysis is developmental rather than preregistered:

- the public source data had already been inspected during programme development;
- the migration classifier is inherited from the source study;
- the 2015 expert exclusions are inherited unchanged rather than re-adjudicated.

Do not tune the 4 km, 0.01 m/s or 1005 m thresholds for the present hypothesis.
